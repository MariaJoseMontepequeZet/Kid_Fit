# Capítulo 5.1 — Preparación del entorno antes de crear una aplicación Flutter con Firebase e IA

## Objetivos

Al finalizar este capítulo el estudiante será capaz de:

* Preparar correctamente el entorno de desarrollo antes de iniciar un proyecto Flutter con Firebase.
* Instalar Flutter en Linux Mint Cinnamon, Ubuntu y Windows.
* Crear y verificar un proyecto Flutter.
* Crear una cuenta Google necesaria para utilizar Firebase y Gemini.
* Crear una cuenta Firebase.
* Comprender qué herramientas deben estar listas antes del Capítulo 6.
* Verificar que todo el entorno funciona correctamente.

---

# 1. Introducción

Antes de comenzar a crear una aplicación Flutter utilizando Firebase e Inteligencia Artificial, es necesario preparar correctamente todas las herramientas.

En el siguiente capítulo se realizará la conexión completa entre Flutter, Firebase y Gemini.

Para evitar problemas durante la práctica, primero debemos tener preparado:

```text
Flutter instalado

↓

Proyecto Flutter creado

↓

Cuenta Google

↓

Cuenta Firebase

↓

Gemini disponible
```

Cada elemento cumple una función:

| Elemento         | Función                                  |
| ---------------- | ---------------------------------------- |
| Flutter          | Crear la aplicación móvil                |
| Proyecto Flutter | Base donde se desarrollará la aplicación |
| Cuenta Google    | Acceder a Firebase y Gemini              |
| Firebase         | Backend y servicios en la nube           |
| Gemini           | Asistente de Inteligencia Artificial     |

# 3. Instalación de Flutter en Linux Mint Cinnamon y Ubuntu

Flutter funciona muy bien en distribuciones Linux basadas en Ubuntu.

Linux Mint Cinnamon utiliza una base compatible con Ubuntu, por lo que los pasos son prácticamente iguales.

---

# 3.1 Actualizar el sistema

Primero abrimos una terminal.

Ejecutar:

```bash
sudo apt update
```

Después:

```bash
sudo apt upgrade
```

Esto actualiza los paquetes del sistema.

---

# 3.2 Instalar herramientas necesarias

Flutter necesita algunas herramientas básicas.

Ejecutar:

```bash
sudo apt install git curl unzip xz-utils zip libglu1-mesa
```

Estas herramientas permiten:

* Descargar Flutter.
* Gestionar versiones.
* Ejecutar comandos necesarios.

---

# 3.3 Descargar Flutter SDK

Crear una carpeta para herramientas de desarrollo:

```bash
mkdir -p ~/development
```

Entrar:

```bash
cd ~/development
```

Descargar Flutter:

```bash
git clone https://github.com/flutter/flutter.git -b stable
```

Después tendremos:

```text
development

└── flutter
```

---

# 3.4 Configurar Flutter en el PATH

Para utilizar Flutter desde cualquier terminal debemos agregarlo al sistema.

Abrir archivo:

Para Bash:

```bash
nano ~/.bashrc
```

Para Zsh:

```bash
nano ~/.zshrc
```

Agregar al final:

```bash
export PATH="$PATH:$HOME/development/flutter/bin"
```

Guardar:

```
CTRL + O
ENTER
CTRL + X
```

Actualizar:

```bash
source ~/.bashrc
```

---

# 3.5 Verificar instalación

Ejecutar:

```bash
flutter --version
```

Debe mostrar información similar:

```text
Flutter 3.x.x
Dart 3.x.x
```

---

# 3.6 Ejecutar Flutter Doctor

Flutter incluye una herramienta de diagnóstico.

Ejecutar:

```bash
flutter doctor
```

Este comando revisa:

* Flutter SDK.
* Android SDK.
* Git.
* Herramientas necesarias.

Ejemplo:

```text
[✓] Flutter
[✓] Android toolchain
[✓] Chrome
[✓] Connected device
```

El símbolo:

```text
✓
```

significa correcto.

El símbolo:

```text
!
```

indica algo pendiente.

# 4. Instalación de Flutter en Windows

---

# 4.1 Descargar Flutter

Ingresar al sitio oficial:

[https://docs.flutter.dev/get-started/install/windows](https://docs.flutter.dev/get-started/install/windows)

Descargar:

```text
Flutter SDK
```

---

# 4.2 Extraer Flutter

Extraer el archivo ZIP.

Ejemplo recomendado:

```text
C:\src\flutter
```

Evitar instalarlo en:

```text
C:\Program Files
```

porque puede causar problemas de permisos.

---

# 4.3 Configurar variables de entorno

Buscar:

```text
Variables de entorno
```

Abrir:

```text
Editar variables del sistema
```

Seleccionar:

```text
Path
```

Agregar:

```text
C:\src\flutter\bin
```

Guardar cambios.

---

# 4.4 Verificar Flutter

Abrir PowerShell:

Ejecutar:

```powershell
flutter --version
```

Debe aparecer:

```text
Flutter version
Dart version
```

---

# 4.5 Ejecutar diagnóstico

Ejecutar:

```powershell
flutter doctor
```

Flutter indicará qué componentes faltan.

# 5. Crear un proyecto Flutter de prueba

Antes de conectar Firebase necesitamos comprobar que Flutter funciona.

Crear proyecto:

```bash
flutter create mi_primer_app
```

Flutter generará:

```text
mi_primer_app

├── android
├── ios
├── lib
├── test
├── pubspec.yaml
└── main.dart
```

---

# 5.1 Entrar al proyecto

Linux:

```bash
cd mi_primer_app
```

Windows:

```powershell
cd mi_primer_app
```

---

# 5.2 Ejecutar aplicación

Ejecutar:

```bash
flutter run
```

Si existe un dispositivo conectado aparecerá la aplicación inicial de Flutter.

Resultado esperado:

```text
Flutter Demo Home Page
```

Esto confirma que Flutter funciona correctamente.

# 6. Crear una cuenta Google

Firebase y Gemini utilizan una cuenta Google.

Si el estudiante ya tiene una cuenta Gmail puede utilizarla.

Si no:

Ingresar a:

```text
https://accounts.google.com
```

Seleccionar:

```text
Crear cuenta
```

---

La cuenta será utilizada para:

* Firebase Console.
* Firebase Studio.
* Gemini.
* Google Cloud.

# 7. Crear una cuenta Firebase

Firebase utiliza la cuenta Google.

Ingresar:

```text
https://firebase.google.com
```

Seleccionar:

```text
Ir a la consola
```

Iniciar sesión.

---

Al entrar por primera vez aparecerá:

```text
Firebase Console
```

Desde aquí se administrarán:

* Proyectos.
* Usuarios.
* Bases de datos.
* Archivos.
* Configuraciones.

---

# 8. Crear acceso a Gemini

Gemini será utilizado como asistente de Inteligencia Artificial.

Ingresar:

```text
https://gemini.google.com
```

Iniciar sesión con la misma cuenta Google.

Verificar que se pueda acceder al chat.

Ejemplo:

Pregunta de prueba:

```text
Explícame qué es Flutter.
```

Si responde correctamente, Gemini está disponible.

# 11. Problemas comunes

## Flutter no encontrado

Mensaje:

```text
flutter: command not found
```

Solución:

Revisar PATH.

Linux:

```bash
echo $PATH
```

Windows:

Revisar variables de entorno.

---

## Git no instalado

Instalar:

Linux:

```bash
sudo apt install git
```

Windows:

Descargar Git desde:

[https://git-scm.com/](https://git-scm.com/)

---

## Flutter Doctor muestra errores

No siempre significa que Flutter esté roto.

Ejemplo:

```text
Android toolchain missing
```

Significa que todavía falta configurar Android.

La configuración completa se realizará según las necesidades del proyecto.
