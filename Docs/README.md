# Documentación Técnica (`/Docs`)

Este directorio centraliza los recursos necesarios para la preparación del entorno de desarrollo y la estandarización de los procesos operativos del proyecto.

---

##  ¿Por qué existe esta carpeta?

La falta de estandarización en los entornos locales y la ausencia de flujos de trabajo unificados suelen generar fricciones, pérdida de tiempo y errores de configuración. Esta carpeta se creó para:

*   **Prevenir inconsistencias:** Evitar el clásico "en mi máquina sí funciona" asegurando que todo el equipo use las mismas versiones y herramientas.
*   **Optimizar el Onboarding:** Permitir que cualquier desarrollador, nuevo o existente, configure su entorno local de forma autónoma, rápida y sin depender de terceros.
*   **Centralizar el conocimiento técnico:** Evitar que los tutoriales, comandos clave y flujos de trabajo se pierdan en chats o notas personales.

---

##  Objetivo

Establecer una **única fuente de verdad técnica** para la instalación de herramientas y la ejecución de procesos. El fin es garantizar un entorno de desarrollo predecible, limpio y alineado con las buenas prácticas de ingeniería del equipo.

---

##  Alcance del Contenido

Para mantener el orden de cara al crecimiento del proyecto, este espacio albergará exclusivamente:

*   **Guías de Instalación:** Configuración del editor, plugins indispensables, SDKs y dependencias globales.
*   **Procesos y Flujos:** Convenciones de Git, estándares de código, flujos de integración y despliegue.
